So, what comes next?

One ladder, one anchor case, four models. Enough to say something about direction and to show the instrument works. Not yet a benchmark.

What we showed

The model reads the crisis you give it

When you slowly strip safeguards away, the estimate moves. In every model we tested, the estimate moved by 20 to 32 points across the full ladder. We set out to test whether models anchor on a famous case instead of the facts in front of them, and the data did not support it. For a staffer at 9 p.m. writing a memo due the next morning, that is good news. The model is not ignoring your scenario.

What it will not tell you is what else it was reading. No model ever mentioned the Cuban Missile Crisis in a single rationale. Asked afterward, every model named it at every rung and through every rewrite. So the assessment on your screen has an input you cannot see, and it stays hidden whether you rewrite the scenario or instruct the model to ignore history.

We did not find evidence that the recognized case distorted the estimate here. We also could have missed the evidence. Establishing that a number came from a precedent rather than from the facts means rerunning the same crisis with the precedent removed, and no user can build that comparison on deadline.

What we can say is that the precedent is present, the model knows it, and the output gives you no way to tell.

Why it matters

Two reasons a staffer will recognize

It takes the argument off the table

Analysts already know how to fight about analogies. Name the precedent, argue the fit, decide. A model that hands you a number with the precedent unstated removes that step entirely.

It looks like confirmation

If the room is already reaching for Cuba, the model agreeing with the room reads as independent corroboration rather than the same instinct arriving twice.

The ask

What the prize would fund

  • More cases

    One ladder is not a benchmark. We plan four more, drawn from precedents that carry different weight in different training corpora: Munich 1938, the Korean War, the 1996 Taiwan Strait crisis, and the Falklands.

  • A ladder that runs the other way

    In the Cuba ladder, every mechanism we strip makes a clash more likely, so the estimate should climb. A model that simply raises its number as bad news accumulates would score the same as one that reasons. We need a case where stripping the mechanisms should push the estimate down, where the safeguards we remove were the things making conflict more likely rather than less. Only a model tracking the causal content will follow both directions.

  • More trials per cell

    Three runs gave us standard deviations above 15 in several cells. That supports a claim about direction and not much more. Ten runs per cell would let us put intervals on the slopes and say which per-rung movements are real.

  • A cleaner way to score recognition

    Right now we count whether the model named Cuba in its rationale, and separately whether it named Cuba when asked. That gives a gap, but it is coarse. We want to score partial recognition, which case gets named when it is not Cuba, and whether the naming changes as mechanisms come out. The elicitation prompt also needs testing on its own, since how the question is asked may set how much the model discloses.

  • More models, including frontier

    We ran four. Adding closed frontier models tests whether disclosure improves with capability, which is the question that decides whether this benchmark stays useful. It also lets us test the mitigation everyone assumes works: if two models reach for the same precedent, checking one against the other buys nothing.

  • A placebo condition

    Nullify framing facts rather than mechanisms. If the estimate rises there too, the slope is tracking hedging density rather than causal content, and we need to know that.
