# AI_Benchmarks_Strategy

### This repo contains the prompts we put into each model, and a synopsis of our results across all runs.

cue_present_prompts.md contains our prompts for L0 - L5

disguise_prompts.md contains our prompts for D0 - D3

The four pdf files list our results for each of the four models we tested across all runs. The number displayed is the probability the model gave each scenario of escalating into a militarized clash based on the facts provided.
